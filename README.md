# Описание программы

Эта программа написана на языке Go и выполняет функции веб-сервера и бота для Telegram. Программа позволяет делать скриншоты экранов и отправлять их либо в ответ на HTTP-запросы, либо в виде изображений в чате Telegram. Программа поддерживает многопоточную обработку запросов и использует стандартные библиотеки Go вместе с библиотеками сторонних разработчиков.

## Основные функции программы:

### 1. **Telegram Bot**

* Программа реализует бота для Telegram, который авторизуется с помощью токена, переданного через флаг командной строки `--token`.
* Бот прослушивает входящие сообщения от пользователей и ожидает, что в сообщении будет содержаться номер дисплея (экранного монитора).
* После получения сообщения бот делает скриншот экрана с указанным номером и отправляет его обратно пользователю в виде изображения в чате.
* Также поддерживается команда `/whoami`, которая сообщает пользователю его `chat_id`.

### 2. **Веб-сервер**

* Веб-сервер слушает HTTP-запросы на порту, указанном в флаге командной строки `--port` (по умолчанию это `8080`).
* При обращении к серверу с GET-запросом на путь `/` и передачей параметра `d` (номер дисплея), программа делает скриншот указанного экрана.
* Скриншот возвращается в виде изображения в формате PNG в ответе на HTTP-запрос.
* Логируется IP-адрес клиента, который сделал запрос на скриншот через веб-сервер.

### 3. **Общие функциональные возможности**

* Программа использует библиотеку `github.com/kbinani/screenshot` для захвата скриншотов с разных дисплеев.
* В случае возникновения ошибок при захвате скриншота, программа предпринимает повторные попытки (до 5 раз), чтобы сделать успешный скриншот.
* Программа разделяет обработку запросов Telegram и HTTP на разные горутины, что позволяет ей обрабатывать сообщения и запросы одновременно.
* В программе реализована проверка на разрешённый `chat_id` (который указывается в флаге `--chat-id`). Запросы от неразрешённых пользователей игнорируются, и попытки получения скриншота также логируются.

### 4. **Ежедневные скриншоты**

* Программа может быть настроена на выполнение ежедневных скриншотов в 00:30 (если включен флаг `--daily`).
* При включении этой опции программа автоматически делает и отправляет скриншот указанного дисплея каждый день в 00:30 по времени сервера.
* Время до следующего запуска логируется.

## Использование программы:

1. **Запуск программы:**

   * Для запуска необходимо указать токен Telegram бота с помощью флага `--token`, разрешённый `chat_id` с помощью флага `--chat-id`, и указать дополнительные параметры (например, `--port`, `--daily`).
   * Пример запуска:

     ```bash
     go run main.go --token="YOUR_TELEGRAM_BOT_TOKEN" --chat-id="123456789"
     ```
   * Для включения ежедневных скриншотов:

     ```bash
     go run main.go --token="YOUR_TELEGRAM_BOT_TOKEN" --chat-id="123456789" --daily=true
     ```

2. **Использование Telegram бота:**

   * Отправьте сообщение боту, содержащее номер дисплея (например, "0" для первого дисплея).
   * Бот ответит вам сообщением, содержащее изображение — скриншот указанного дисплея.
   * Для получения своего `chat_id`, отправьте команду `/whoami` в чат с ботом, и бот ответит вашим идентификатором.

3. **Использование веб-сервера:**

   * Откройте браузер и перейдите по адресу `http://localhost:8080/?d=0`, где `d=0` — номер дисплея.
   * В ответ вы получите изображение в формате PNG, содержащее скриншот указанного дисплея.

4. **Ежедневные скриншоты:**

   * Если флаг `--daily` активирован, программа будет отправлять ежедневный скриншот в 00:30. Логируется информация о времени, через которое сработает следующий скриншот.

### Примечания:

* В случае возникновения ошибок, связанных с захватом изображения (например, если дисплей не существует), программа попытается сделать скриншот до 5 раз перед тем, как отказаться от попытки.
* Программа работает в многопоточном режиме, что обеспечивает её эффективность при одновременной обработке запросов Telegram и HTTP.
* Логируются IP-адреса клиентов, которые делают запросы на скриншот через веб-сервер, что помогает отслеживать и предотвращать несанкционированный доступ.

### Пример логов:

* При отправке сообщения с номером дисплея:

  ```
  2025/05/05 12:34:56 Received screenshot request from IP address: 192.168.1.5
  2025/05/05 12:34:58 Captured screen #0: 0_1920x1080.png
  2025/05/05 12:35:01 Sent screenshot to user chat ID 123456789
  ```

* При выполнении ежедневного скриншота:

  ```
  2025/05/05 00:30:00 Daily screenshot will be sent in 0h0m0s
  2025/05/05 00:30:10 Sent daily screenshot to chat ID 123456789
  ```

* При попытке несанкционированного доступа через веб-сервер:

  ```
  2025/05/05 12:34:56 Unauthorized access attempt from chat ID 987654321
  ```
